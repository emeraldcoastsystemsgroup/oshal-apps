# Connected application workflows

The reviewed-context Home release is implemented. [App-by-app results](APP-HOME-EXTRACTION-PLAN.md) give all 53 public packages a source-backed summary or a documented launcher/simulation disposition. [Contract coverage](APP-INTEGRATION-COVERAGE.md) lists every destination, artifact receiver and required app dependency. [Release evidence](APP-HOME-COMPLETION.md) records installation and acceptance.

| Process | Delivered behavior |
|---|---|
| Discover tools for a business process | Capability Ideator reads loaded app actions, preserves its existing Studio worker identity, and develops proposals with primary-source references, required/optional dependencies, connection scopes, review points, success metrics and acceptance criteria. Selected evidence continues into an editable Office or Venture brief. A completed discovery run is not an implemented integration. |
| Prepare for an upcoming event | Calendar explicitly syncs a minimized primary-Google-calendar snapshot. Select an event to discuss gifts with Shopping, meals with Eats, travel with Travel, or meeting preparation with Office. Shopping owns preference/budget discussion and retailer deep links; Home does not infer a recipient profile or buy a gift. |
| Turn information into useful work | World, Feeds and saved Email evidence open research, communication, venture, campaign or Sales drafts where their declared eligibility and access rules allow it. Recorded ingestion and digest generation times remain visible. Social uses saved inbox notifications and clearly identifies that coverage. |
| Move career work forward | Job Apply distinguishes verified submission evidence from manual marks and unknown outcomes; selected work opens Career review and then an editable Social networking draft. Career uses personal score cohorts, tracked applications and recorded interviews. Existing document exports remain available. |
| Reconcile business activity | Payments and Payroll open Finance review; Finance opens Office. Trading and Kalshi distinguish paper/live evidence and open research or Recap drafts. Nothing about opening a draft settles funds, places an order or retries a submission. Private Sales uses authorized CRM books and explicit customer/opportunity/conversion cohorts. |
| Continue creative production | Office, Marketing, Venture, Vids and Video exchange selected briefs. Brand, Creative Studio and Recap have native review screens. Portrait, LoRA, Storage and Print provide saved result/intake evidence where enabled. Brand rendering remains an explicit confirmed Vids action; disabled Brand stays unavailable to Office/Marketing. |
| Plan household activities | Travel, Rides, Eats, Shopping, Movies and Spotify exchange visible editable planning drafts, including disconnected states. Saved conversations and preferences are not completed bookings, orders or live playback. |
| Review operations and simulations | Camera, Drone, Spaces, Smart Home, Sat Ops and Cloud show their actual saved or observed source state. Diagnostic drafts continue into Office. Aero/Ocean explicitly capture visible simulation results; simulation, accepted commands, mission starts and physical completion remain distinct. |
| Prepare learning and recreation | Little Monsters selects authorized classwork for an Office study plan. Kid Lens can share a reviewed saved parent brief with Shopping or Office. D&D recaps and hosted Game Show records support documents or meal planning. Pumpkin dialogue becomes a Vids draft, Bake-Off results become a comparison brief, and followed Sports previews support meal/travel discussions. |

Every context exchange has a declared source offer, a compatible versioned target receiver and actual editable destination controls. The runtime checks loaded destinations when rendering and again when clicked. App dependencies are required only for functionality that cannot work without them; optional action partners remain optional. A provider connection is checked by the destination when the user explicitly asks it to sync, research or execute. Saved connection metadata does not prove provider liveness.

Home reads are side-effect free. Partial sources remain unavailable, never invented zeroes. Account ownership, campaign membership, school tenant/issuer and CRM authorization remain enforced. A school setup gap returns an app-local access error rather than redirecting all of Home to login. Disabled apps are an activation choice, independent of card visibility preferences.

All boxes and metrics default on, with saved visibility and ordering. Core groups compose active member evidence; suites provide highlights. Life, Games and System retain compact launchers because they own no separate ledger. Stateless labs provide explicit analysis capture rather than fabricated activity histories.

The implementation deliberately stops at review boundaries. Automatic semantic event deduplication, automatic provider execution, newly inferred dataset-ingest permissions and automatic booking reconciliation are not part of this release. Existing file receivers retain their own authorization and import paths. New external-tool proposals must be verified and implemented before being described as connected or available.
