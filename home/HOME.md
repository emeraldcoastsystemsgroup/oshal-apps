# home on Home

Shows the exact caller's cached device index and saved scene counts with the recorded device-index time. A missing file is Not indexed, never zero. Reads the existing process overlay after an explicit refresh. Invalid, oversized, cross-owner or symlinked snapshots fail closed. No refresh, assistant, switch or scene execution runs on Home. Prepare a diagnostic brief with counts and age; device identifiers and home locations are not transferred.

Every declared metric defaults on and can be hidden or reordered. Summary GET requires an authenticated session. Source failure returns unavailable, not healthy or empty.
