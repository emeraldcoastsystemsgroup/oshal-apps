Sat Ops — operator guide

Satellites are swarm nodes (ADR-102). Each sat runs its own ADCS — MEKF attitude estimation, a SAFE/DETUMBLE/SLEW/POINT/DESAT mode manager, magnetorquer momentum dumping — against a simulator engine (in-process RK4 or the NASA 42 referee). Every engine is a simulator; commands cannot reach hardware by construction, and every command still requires your explicit Approve.

Fleet (attitude nodes) — live sats heartbeating in. Dot = online; chip = ADCS mode; number = pointing error. Click a row to select. A sat appears here when a node process is running (npm run sat:node) — orbit catalog entries alone don't heartbeat.

Orbit catalog (TLE) — orbit identity, deliberately separate from attitude nodes; the two join by sat id. Paste any two/three-line element set, or Seed demo fleet (leader + a 5.9 km trailing chaser + a polar bird). Registering a TLE draws its orbit in the 3D console and its ground track on the map.

3D console — drag to orbit the camera, wheel to zoom, auto-rotate toggles the idle spin. frame: inertial shows ECI (TEME) with the Earth graticule rotating at GMST; frame: earth holds the globe still. The selected sat shows its body-axis triad (red/green/blue = x/y/z from the node's quaternion). Rings with km labels are conjunction events at their time of closest approach.

Conjunction screening — pairwise SGP4 close-approach search over the catalog inside the horizon; events list TCA, refined miss distance, and relative speed. A screening aid for the sim fleet: point geometry only — no covariance, no collision probability.

Selected sat — live telemetry: mode + transition reason, pointing error, wheel momentum (with dumping when the rods are active), body rate, MEKF health (updates/rejections/reinits, attitude σ, gyro bias estimate).

Command console — SAFE (sticky fault floor: zero torque, never auto-exits), DETUMBLE (rate damp; auto-completes or resumes a latched target), DESAT (dump wheel momentum, then return to the latched target), POINT (slew axis + angle; the node runs SLEW→POINT with hysteresis and refuses while the attitude estimate is unhealthy). Every send passes an Approve dialog.

Sat operator (drafts only) — describe intent in plain language ("point sat42-live 30° off current", "why is momentum high?"). The concierge replies and may offer a validated draft; Load draft only pre-fills the console — you still press the command button and Approve. It never sends anything itself.

Pass windows — pick a catalog sat and a ground station (lat/lon/alt); predicts 24 h of contacts (rise/set, duration, max elevation) via SGP4.
