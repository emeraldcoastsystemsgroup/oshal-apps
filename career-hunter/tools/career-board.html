How submitting works — 2 things to set up first
  1. Install an OSHAL leaf node on the computer that has your logged-in Chrome — your own desktop, or a remote box you've joined to the swarm — with screen control enabled. The browser is driven with real clicks/keystrokes, so it runs in the foreground on that machine (no headless mode) — leave it signed in and awake.
  2. Keep the target-site account ready on that desktop. Account sign-in, email/SMS codes, and CAPTCHAs pause the run in Needs you; complete those challenges yourself on the target machine.
  3. Pick the target computer in the On … dropdown above (or leave it on auto-pick), then hit Submit. Watch each run in the Submissions tab.
Offline Apply / Autofill — no worker or running stack needed after setup
  1. Click Copy offline autofill bookmarklet, create a browser bookmark, and paste the copied javascript: URL into that bookmark's address.
  2. Open a supported Ashby, Greenhouse, Lever, Workday, or Distyl application, then run the bookmark. OSHAL fills only empty visible fields and does not directly upload, click, navigate, call the network, create an account, answer demographic questions, or submit.
  3. The bookmark emits normal field-change events so React-style forms retain the values. Employer page scripts can react to those events, so keep the page in view and verify every result before continuing.
  4. Privacy: the bookmark URL contains your contact/application profile. Keep it out of shared or browser-synced profiles, and delete it when you no longer need it.
