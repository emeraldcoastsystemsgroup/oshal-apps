# ParaView — evaluation (2026-09-13)

**What it is.** Open-source scientific visualisation on VTK. Its licence page (paraview.org/license,
read 2026-09-13) states "ParaView uses a permissive BSD 3-Clause license". The user guide
(docs.paraview.org, read 2026-09-13) describes `pvpython` as "the Python interpreter that runs
ParaView's Python scripts", `pvbatch` as the same "designed for batch processing" that "can be run
in parallel", and `pvserver` as "the server that does all of the data processing and, potentially,
the rendering". Headless (OSMesa / EGL) binaries and docker images were not read on the pages
fetched (*unverified*).

**The question.** Server-side rendering in a container to images or glTF the cockpit can show,
versus the existing in-browser viewers; size of the image and time per frame.

**Answer.** The shape is sound and the licence is permissive: a container with a headless
ParaView build runs `pvbatch` scripts that turn a field result (an OpenFOAM case, a scalar field on
the embodied map) into PNG frames or glTF the cockpit already knows how to show. The numbers
asked for (image size, seconds per frame, container size) need the container to exist; today no
lab here produces a field result, so there is nothing to render yet. The in-browser viewers
(the embodied map, CAD Studio's model view) cover every result the labs produce now.

| | Cost | Benefit |
|---|---|---|
| Build | a headless ParaView container (hundreds of MB), pvbatch scripts per result kind, a route that serves frames | isosurfaces, streamlines, cut planes — what an in-browser viewer would have to re-implement |
| Run | seconds per frame on CPU | — |
| Risk | premature: no field results exist yet | — |

**Verdict.** A BACKLOG item held until a producer exists, **B16 — server-side field rendering**.
Done when: a lab produces a field result (the OpenFOAM note is the likely first), a container
renders it through pvbatch to PNG and glTF served under the owning package's route, and the
image size and time per frame are recorded from that run.

**Evidence.** https://www.paraview.org/license/ and https://docs.paraview.org/en/latest/UsersGuide/introduction.html (fetched 2026-09-13).
