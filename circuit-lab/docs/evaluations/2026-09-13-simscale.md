# SimScale — evaluation (2026-09-13)

**What it is.** Cloud CAE (CFD, FEA, thermal). The SimScale Python SDK repository
(SimScaleGmbH/simscale-python-sdk, read 2026-09-13) states the API authenticates with an
`X-API-KEY` header, that "API access is currently part of our paid Enterprise plan" (development
partners may ask api@simscale.com), and that the SDK itself is MIT. Compute pricing was not
stated on the page read (*unverified*).

**The question.** Cost per case, egress of geometry, and result fidelity versus a local
OpenFOAM / CalculiX container for the propeller and bracket cases the drone design needs.

**Answer.** The API is Enterprise-only, so cost per case cannot be evaluated on the plans a
person has; every case would upload the geometry (the airframe, the propeller) to a third party,
which the labs' local posture (ADR-152, ADR-153, ADR-154) rejects; and fidelity cannot be
compared without running the cases, which the plan gate prevents.

| | Cost | Benefit |
|---|---|---|
| Use | an Enterprise plan; geometry egress on every case; credentials on the box | managed meshing and solvers, no local compute |
| Local alternative | an OpenFOAM / CalculiX engine container (see the OpenFOAM note) | the same posture as every lab here: nothing leaves the box |

**Verdict.** A recorded **no**. Revisit only if a plan a person can hold exposes the API and the
operator decides geometry may leave the box for a named case.

**Evidence.** https://github.com/SimScaleGmbH/simscale-python-sdk (fetched 2026-09-13).
