# Engineering Equation Solver (EES) — evaluation (2026-09-13)

**What it is.** A commercial equation solver with built-in thermodynamic and transport property
functions (F-Chart Software). Its site (fchartsoftware.com/ees, read 2026-09-13) states EES
"operates with Microsoft Windows operating systems (10 and 11)"; licences are student (one year),
commercial / professional and academic site licences (prices not on the page read); on Linux it
"operates under Linux using Wine" with instructions written for Ubuntu 9.10 and Wine 1.1.32; there
is no native macOS version (virtualisation or Wine). No API or automation interface is described
beyond user-written function libraries.

**The question.** Licensing for a package on a person's box, and whether an open stack (CoolProp
for properties, a SciPy / SymPy solver behind route-backed tools) covers the sizing problems
actually posed.

**Answer.** A Windows-only commercial program under Wine, licensed per user, with no automation
interface, cannot be a package the swarm drives. The problems the labs pose (a propulsion sizing,
a thermal budget, an equation set with property lookups) are what an open stack does: CoolProp
(MIT) for fluid properties, SciPy for the solve, SymPy for the symbolic step, behind the same
route-backed tools every lab here uses.

| | Cost | Benefit |
|---|---|---|
| EES | a per-user commercial licence, Wine, no API, Windows semantics inside a Linux container | the property library and a solver people already know |
| Open equation lab | a small package: CoolProp + SciPy + SymPy in an engine container, a contract for an equation set, route-backed tools | local, drivable by the concierge, no licence per box |

**Verdict.** A recorded **no** for EES; a BACKLOG item for the shape it stood for, **B14 — an
equation lab**. Done when: a package solves a named equation set with CoolProp properties behind
route-backed tools, a textbook case (a Rankine-cycle or a heat-exchanger sizing) solves to the
published numbers in a real-solver test, and the concierge can pose and read one.

**Evidence.** https://fchartsoftware.com/ees/ and https://fchartsoftware.com/ees/mac-linux.php (fetched 2026-09-13).
