# NASA CEA — evaluation (2026-09-13)

**What it is.** Chemical Equilibrium with Applications: combustion equilibrium and rocket
performance (Isp, chamber temperature). NASA's software catalog entry LEW-17687-1 (read
2026-09-13) lists it as "U.S. and Foreign Release" and describes "theoretical rocket performance,
Chapman-Jouguet detonation parameters, shock-tube parameters, and combustion properties". The
RocketCEA wrapper (sonofeft/RocketCEA, read 2026-09-13) is GPL-3.0, bundles Fortran source in
`NASA_CEA_Fortran` with "many modifications" for f2py, builds with meson and needs a Fortran
compiler, and supports Python 3.7–3.14. RocketCEA's page does not restate NASA's own terms.

**The question.** Licence terms for redistribution in a package container, RocketCEA build on
`python:3.11-slim`, and a validation case against a published motor.

**Answer.** Redistribution: the catalog lists a U.S. and foreign release, and RocketCEA carries
the Fortran under GPL-3.0 — a locally built, never-published container (the ngspice posture) is
consistent with both; the exact catalog usage agreement text was not read and must be before a
container is built (*unverified*). The build needs `gfortran` and meson on top of the slim image
(a few hundred MB more); it was not attempted. A validation case exists in the literature (any
published motor's Isp at a stated chamber pressure and expansion ratio) and is the test the
container must pass.

| | Cost | Benefit |
|---|---|---|
| Build | gfortran + meson + RocketCEA in an engine container; a contract for a propellant / chamber / nozzle case | Isp, chamber temperature and exhaust properties for the rocket lane's motors, locally |
| Run | milliseconds per case | — |
| Risk | the usage agreement text unread; the f2py build on slim Debian untried | — |

**Verdict.** A BACKLOG item folded into **B15 — the rocket lane** (with OpenRocket), done when:
the NASA usage agreement for LEW-17687-1 is read and quoted in the package, RocketCEA builds in a
container from `python:3.11-slim-bookworm` with the image size recorded, and a published motor's
Isp at its stated chamber pressure and expansion ratio is reproduced within 1 % in a real-solver
test.

**Evidence.** https://software.nasa.gov/software/LEW-17687-1 and https://github.com/sonofeft/RocketCEA (fetched 2026-09-13).
