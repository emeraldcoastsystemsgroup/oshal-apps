# Onshape — evaluation (2026-09-13)

**What it is.** Cloud parametric CAD with a public REST API and FeatureScript. The developer
documentation (onshape-public.github.io/docs, read 2026-09-13) lists two authentication paths:
OAuth2 ("All applications must authenticate with OAuth2 to be approved in the Onshape App Store")
and API keys, which "authenticate an application, NOT its users, and will only perform operations
on behalf of the Onshape user who generated the API keys". An Import & Export guide and an API
Limits page exist; the formats and limits were not read (*unverified*).

**The question.** As an import / export connector only: can a person open one of their Onshape
documents as a STEP base in CAD Studio, and push a CAD Studio revision back, without the model
leaving the box except by their explicit action?

**Answer.** Yes in shape. ADR-153 chose a local OCCT kernel and rejected cloud CAD *as the
kernel*; that decision stands. A connector is a different thing: the person's own API key (or an
OAuth grant registered under the business email, `docs/partner-app-registration.md` shape A)
fetches a STEP export of a document they name and posts it to CAD Studio's existing STEP import;
the reverse direction uploads a CAD Studio STEP as a new Onshape document version. Every transfer
is the person's click, so nothing leaves the box otherwise. What is not known yet: which
subscription plans may mint API keys (the auth page does not say), and the export rate limits.

| | Cost | Benefit |
|---|---|---|
| Build | a connector (OAuth registration under the business email, or an API-key field), two routes, a CAD Studio import hook | a person's existing Onshape library becomes printable / editable here without re-modelling |
| Run | none on the box; egress only on the person's explicit import / export | the round trip keeps Onshape as the collaboration surface and this box as the kernel |
| Risk | plan / rate-limit unknowns; a model that leaves the box is the person's decision each time | — |

**Verdict.** A BACKLOG item, not built now: **B12 — Onshape import / export connector**. Done
when: a document the person names opens as a STEP base in CAD Studio through their own credential,
a CAD Studio revision pushes back as a new Onshape version, both only on their click, the plan /
rate-limit facts are recorded from the API Limits page, and the connector is registered under the
business email per `docs/partner-app-registration.md`.

**Evidence.** https://onshape-public.github.io/docs/ and https://onshape-public.github.io/docs/auth/ (fetched 2026-09-13).
