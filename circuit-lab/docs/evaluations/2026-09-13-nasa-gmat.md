# NASA GMAT — evaluation (2026-09-13)

**What it is.** The General Mission Analysis Tool: spacecraft trajectory and mission design. The
SourceForge project page (read 2026-09-13) states the licence is "Apache License V2.0", the
platforms "BSD, Linux, Mac, Windows", and the latest release R2026a (2026-04-03). The R2020a
release README (read 2026-09-13) refers to a "Python interface" and a "MATLAB interface" and to
driving GMAT "from a custom script language"; installers of ~330–350 MB per platform are listed
for that release.

**The question.** Does GMAT's propagation and manoeuvre planning in an engine container replace
or check the propagation sat-ops uses today, and at what container size?

**Answer.** The licence and platforms allow a package-owned container; the Python interface
makes a worker the same shape as this lab's. Whether it *replaces* sat-ops' propagation is a
question for sat-ops' own numbers: the honest first use is a cross-check — the same two-line
element propagated by both, the position difference recorded over the campaign window. The
container size is bounded below by the ~350 MB Linux installer and must be measured.

| | Cost | Benefit |
|---|---|---|
| Build | an engine container (~350 MB installer plus a JRE / Python runtime), a worker that runs a script and returns ephemerides | a mission-grade propagator and manoeuvre planner as a local, drivable check |
| Run | seconds per propagation | — |
| Risk | the Python interface's exact API surface was not read (*unverified*) | — |

**Verdict.** A BACKLOG item in sat-ops, done when: a container propagates one campaign TLE
through GMAT's Python interface, the position difference to sat-ops' propagator is recorded over
30 days, the container size and time per propagation are recorded, and sat-ops decides from those
numbers whether GMAT replaces or checks.

**Evidence.** https://sourceforge.net/projects/gmat/ and https://sourceforge.net/projects/gmat/files/GMAT/GMAT-R2020a/ (fetched 2026-09-13).
