# ADR0033: Project historical RCAs from their canonical sources

Installed and browser-accepted, 21 October 2026: catalogue, original work receipts, input lineage and accepted report links are visible.

Add a historical RCA library over current-user canonical tickets, completed work
receipts, input lineage and accepted workspace artifacts. Preserve one source of
truth for reports. Reuse the Systems split-panel layout and native navigation.
Do not claim the topology correlation tables are a reviewed RCA case library.

Keep report acceptance separate from infrastructure recovery and preserve partial
lineage or unavailable sources. Require exact original-ticket download selectors,
render untrusted report text safely, and clear private views on refusal or stale
selection. The default Systems refresh also uses the same resolved page key as
navigation so an empty/unknown hash cannot erase its only graph read.

[RCA-LIBRARY.md](../RCA-LIBRARY.md) records current limits and subsequent scoped
retrieval work. There is no automatic RAG ingestion, cross-case cause inference,
terminal execution or expanded bot authority in this increment.
