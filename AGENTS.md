# Delivery instructions

The operator requires completed changes to be committed and pushed as work proceeds.
Use small, coherent commits and run the checks required by CONTRIBUTING.md. Do not
leave completed work only in the working tree. Stage only the files owned by the
current task; preserve unrelated work. Use normal pushes, keep hooks enabled, and
resolve remote divergence without overwriting another contributor's commits.
Report commit IDs, push destination, verification results and any unfinished scope.
