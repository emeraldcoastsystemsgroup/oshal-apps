            Choosing iPhone vs Android: iPhones never need Developer Mode or a 6-digit pairing code — use Pair an iPhone (Bluetooth OSHAL-KB + AirPlay OSHAL Mirror). Android phones use Pair an Android phone next to it.

            Pair an iPhone

            No Developer Mode or pairing code needed. This computer acts as a Bluetooth keyboard peripheral called OSHAL-KB (pairing always starts on the iPhone in Settings → Bluetooth → OSHAL-KB, not from a computer scan) and as an AirPlay receiver for live screen mirroring.

            1. Step 1 (See Screen): Press Start mirroring, then on your iPhone swipe down Control Center → Screen Mirroring → OSHAL Mirror on the same Wi-Fi (no iPhone app install needed!).
            2. Step 2 (Connect Controls): Press Pair an iPhone (opens a 2-minute window), then open Settings → Bluetooth → tap OSHAL-KB under Other Devices, tap Pair, and press Add below.
            3. Step 3 (Tap & Swipe): Turn ON Settings → Accessibility → Touch → AssistiveTouch so pointer taps and swipes work live.

            Pair an Android phone

            Enabling Developer Mode alone does not pop up a code — open Wireless debugging inside Developer options to get the 6-digit pairing popup.

            1. Step 1 — Samsung Auto Blocker (Samsung Galaxy): Open Settings → Security and privacy → Auto Blocker and turn it Off (Samsung blocks both APK installation and Wireless debugging while Auto Blocker is on).
            2. Step 2 — Allow Restricted Settings (Android 14 / 15 / 16): After installing the Open Swarm APK, Android initially blocks Accessibility permissions with “Restricted setting”. Open Settings → Apps → Open Swarm → tap ⋮ (top-right corner) → Allow restricted settings and verify your PIN/biometric.
            3. Step 3 — Turn ON Swarm Touch Control & Join Swarm: Open Settings → Accessibility → Installed apps → Open Swarm → On, then open the Open Swarm app, tap ⚙ Swarm Node & Remote Control, turn Swarm Control: ON, and tap Join Swarm. Your phone will appear automatically under Phones & TVs with live screen picture and touch control!
            4. Optional — Direct Wireless Debugging (ADB without APK): After tapping Build number 7 times, open Settings → Developer options → tap the words “Wireless debugging” on the left side, turn it ON (Allow on this network), and tap Pair device with pairing code to enter the 6-digit code + IP:port below.

            Connect a TV (Fire TV / Android TV)

            Enter your Fire Stick IP (or scan Wi-Fi) and press Load oshal TV — connects, waits for Allow, installs the signed oshal TV app and launches it in one step.

            1. Using your remote or the Fire TV phone remote app: Settings → My Fire TV → About → tap Fire TV Stick 7 times → Back → Developer Options → turn ADB Debugging ON (and note IP Address under About → Network).
            2. Press Find TVs on Wi-Fi (or enter the Fire Stick IP below) and press Load oshal TV.
            3. When the TV asks Allow USB debugging?, tap Allow using your remote or the Fire TV phone remote app — installation continues automatically.
