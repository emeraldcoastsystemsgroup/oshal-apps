Scene Studio makes Godot games and 3-D scenes and Blender models. You and the swarm drive Godot and Blender through their MCP servers.

Pick New, choose what to make, then ask the Scene Studio director in the chat to build it — for example "a small island with three palm trees and a red boat" — or edit it here.

Every change is a revision you can undo. Previews are rendered by Blender; a Godot scene is exported to glTF first. Code you or the director write runs in the engine's sandbox, which has no network access.

The Scene Studio engine container is not answering.
Install or rebuild it from the host:

Source editing is available. Running project code, Godot tools, model import and rendering require execution access.
