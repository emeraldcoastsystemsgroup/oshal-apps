## The single assumption whose falsity kills it

**`B-04` — that a projector with a 0.5–0.8 throw ratio and a measured 150–400 ANSI lumens exists at $28.00–$85.00 in five-thousand-unit quantities.**

It is the top of the sensitivity chart on its own merits, moving the peak cash requirement by $270,410 across its range. It is the only single driver whose movement turns the big-box configuration contribution-positive, at $39.91. And the dataset flags the band itself as unsafe: the cheap projector class this price assumes is built around a 1.2–1.5:1 throw ratio, which does not close the geometry inside a six-foot envelope.

So the number that carries the most weight in the plan is attached to the question nobody has asked. If the required optics are only available in the higher module tier, the premium tier's bill of materials rises past every price point in this document set and the tier is over. If a supplier confirms the band, the venture has its first quoted line and the plan is worth rebuilding.

**Everything else in this register can be worked around, deferred or designed out. This one is a phone call and a fact.**

## What is NOT a fatal flaw, and is often mistaken for one

Four things that sound like showstoppers and are not, each closed by arithmetic rather than by reassurance:

- **A grey glowing rectangle from a cheap projector.** PASS, and this is a case where doing the arithmetic overturned the intuition. The obvious fear - that a cheap projector paints a grey box on the pumpkin - is wrong in a typical suburban yard because the shipped preset renders a PURE BLACK background (SW-2), so the black field is at 0.07 to 0.
- **Cooking the inside of the inflatable.** PASS. A cold-air inflatable is not sealed - the blower runs continuously and the fabric leaks by design (A-THM-3), so the interior is a moving air stream, not an oven.
- **Being invisible in a yard.** PASS after dark, FAIL before dark. The worst-case corner of the input bands still gives 32:1 contrast in a dark yard, so this is robust rather than marginal.
- **Needing more than one household outlet.** PASS with wide margin. One 16 AWG outdoor cord on one GFCI outlet.

**The physical form factor is not a risk either.** A projection inflatable of this kind ships today at an observed $99.99 retail, which demonstrates that a projector inside a cold-air inflatable, outdoors, for a full season, is a solved manufacturing problem. This venture is not inventing the form factor; it is putting a different light engine inside a proven one. That incumbent is simultaneously the reason the value tier has no price headroom.
