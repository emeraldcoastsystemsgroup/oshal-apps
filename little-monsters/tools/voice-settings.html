How the defaults are changed (operators)

Operator defaults come from the voice block in the installed Little Monsters oshal-app.yaml. Publish the manifest change, reinstall with node scripts/oshal-app.js install little-monsters, then restart the controller. The personal choices above remain device-local.

voice.tts.provider = "—" → change to "browser" | "gemini-tts" | "google-cloud-tts" voice.stt.provider = "—" → change to "browser" | "gemini-stt" | "google-cloud-stt"
