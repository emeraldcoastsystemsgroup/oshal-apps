Calling Assistant

Set up a phone task once, let the calling service handle the menu, and join when a person answers.

1. Connect and configure

Open Connections to add Twilio, then select it here. Calling starts disabled. These settings belong to your account; background tasks run for you using the connection you select.

2. Check recorded audio

Upload a WAV containing a claims menu, hold music, or an agent greeting. This uses the same audio interpreter as a phone task and shows its transcript and decision.



3. Run a call
The service listens in short turns. Unknown or ambiguous menus wait; an approved reply can speak or send digits. A recognized human greeting rings your handoff phone.









Each submission receives an idempotency key to prevent a retry from dialing twice.
